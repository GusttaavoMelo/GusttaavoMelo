## 🚀 Featured Work

### 📚 Páginas Eternas

> **Onde cada página guarda uma nova aventura.**

A modern online bookstore built with **React and TypeScript**, created to explore a more complete front-end application architecture.

The project currently includes:

* 📖 Book catalog and search
* 🔎 Filters by category, author and price
* ❤️ Favorites
* 🛒 Shopping cart
* 👤 Authentication
* 💳 Checkout
* 📦 Order management
* 📱 Responsive interface
* 💾 Local data persistence

**Stack:** React · TypeScript · Vite · React Router · TanStack Query · Axios · React Hook Form · Zod · Context API · CSS Modules

> 🚧 **Currently under development** — the application is online, but new features and improvements are still being implemented.
